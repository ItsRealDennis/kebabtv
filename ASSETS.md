# KebabTV: asset list

Loose pieces for the website. Not finished scenes, heroes or banners.

## Rules for every asset

- **PNG with a transparent background.** One object per file, centered, with a little empty space around it.
- **Size:** 1024 × 1024 px (icons: 512 × 512).
- **Style:** same as the logo. Thick black outline, flat colors, slightly hand-drawn, a bit retro.
- **Colors:** yellow `#F3DC07`, red `#C93118`, dark red `#730A03`, black, white. Food keeps its own colors (bread, salad, foil).
- **No shadow** (the website adds it). **No background.** No text, except where it says so.
- Put the files in: `site/public/assets/`
